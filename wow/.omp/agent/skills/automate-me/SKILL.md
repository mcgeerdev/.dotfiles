# Automate me

## Process

1. Read recent transcripts for repeated instructions, corrections and rejected approaches.
2. Keep only patterns that appear three or more times.
3. Write each pattern as a rule with a trigger, not as prose describing the user.
4. Cite the evidence for each rule in one line.
5. Hand back the draft for correction before installing it anywhere.

## Rules

- An instruction given once is a preference, not a pattern. Leave it out.
- Drop anything the existing agent rules already cover.
- If a check or lint rule could enforce the behaviour, propose that instead.
- Quote the user's own words for the rules they stated explicitly.
