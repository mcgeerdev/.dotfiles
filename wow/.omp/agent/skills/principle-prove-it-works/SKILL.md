# Prove it works

Verify against the real artifact, not a proxy for it.

- Run the feature. Read the actual value. Inspect the diff.
- "It compiles" and "the test I just wrote passes" are not evidence of behaviour.
- Name what you ran and what you saw, in the same breath as the claim.
- Where verification was impossible, say so beside the claim rather than in a footnote.
- A screenshot, a command's output, or a log line beats a paragraph of confidence.
